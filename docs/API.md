# API-документация

Программа - CLI, HTTP-эндпоинтов у неё нет (по условию задания достаточно скрипта/CLI). Поэтому «API» здесь - это аргументы командной строки, форматы входных и выходных данных и коды возврата. Ту же роль для программного использования играет функция `contract_report.calculator.calculate(dataset, as_of)`.

## Командная строка

```
python3 -m contract_report [-d ДАТА] [--data-dir КАТАЛОГ] [-f {table,json,csv}] [-c ID] [-o ФАЙЛ]
```

(после `pip install -e .` то же самое делает команда `contract-report`)

| Аргумент | По умолчанию | Описание |
|---|---|---|
| `-d`, `--date` | сегодня | Дата отчёта: `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`. Учитываются только события, датированные этим днём **включительно** и раньше |
| `--data-dir` | `./data` | Каталог с `contracts.csv`, `works.csv`, `payments.csv` |
| `-f`, `--format` | `table` | `table` - текст для консоли, `json`, `csv` |
| `-c`, `--contract` | все | Показать только один договор (по `contract_id`) |
| `-o`, `--output` | экран | Записать отчёт в файл (UTF-8) вместо вывода на экран |

### Коды возврата

| Код | Значение |
|---|---|
| `0` | отчёт построен (предупреждения кода не меняют) |
| `2` | неверные аргументы: нечитаемая дата, неизвестный формат, договор `-c` не найден |
| `3` | ошибка входных данных: нет файла или колонки, битая сумма/дата/статус, ссылка на несуществующий договор или работу и т.п. |

Отчёт - в `stdout`, сообщения об ошибках - в `stderr`. При ошибке `stdout` пуст.

## Входные данные

Три CSV в UTF-8 (BOM допустим), разделитель - запятая, первая строка - заголовок. Исходное описание колонок - `data/FORMAT.md`. Что именно проверяет загрузчик:

| Поле | Правило |
|---|---|
| `amount`, `price` | положительное число, не более двух знаков после точки; `1e3`, `NaN`, `1,5`, `-5`, `100.005` отвергаются |
| даты | строго `ГГГГ-ММ-ДД` |
| `work.status` | `planned`, `done`, `cancelled` |
| `payment.status` | `paid`, `queued`, `refunded` |
| платёж `paid` | обязателен `paid_at` |
| платёж `refunded` | обязательны `paid_at` и `refunded_at`, возврат не раньше оплаты |
| платёж `queued` | `paid_at` должно быть пустым |
| идентификаторы | уникальны в своём файле |
| ссылки | `works.contract_id` и `payments.contract_id` существуют; `payments.work_id` (если задан) существует **и принадлежит тому же договору** |

Лишние колонки игнорируются. Пустое `work_id` в платеже - платёж без привязки к работе.

## Выходные форматы

### `table`

Для чтения человеком: по каждому договору таблица работ и блок итогов, затем «Всего по договорам» (если договоров больше одного), список пропущенных договоров и предупреждения. Суммы в виде `300 000,00`.

### `json`

Суммы - **строки** с двумя знаками (`"185000.00"`), чтобы JSON-парсер не превратил их в `float`.

```jsonc
{
  "as_of": "2026-11-10",
  "contracts": [
    {
      "contract_id": "D-1",
      "contractor": "Студия «Свет»",
      "signed_at": "2026-08-25",
      "contract_amount": "600000.00",   // сумма договора из учёта
      "cancelled_amount": "100000.00",  // цены работ, отменённых к дате отчёта
      "payable": "500000.00",           // contract_amount - cancelled_amount
      "paid": "315000.00",              // выплачено за вычетом возвратов
      "remaining": "185000.00",         // max(payable - paid, 0)
      "overpaid": "0.00",               // max(paid - payable, 0)
      "accepted_unpaid": "0.00",        // остаток по принятым работам
      "unallocated": "15000.00",        // выплачено, но не закреплено за работами (аванс)
      "queued": "150000.00",            // в очереди, деньги ещё не ушли
      "queued_payment_ids": ["P-4"],
      "works": [
        {
          "work_id": "W-14",
          "title": "Съёмка: осень",
          "state": "done",              // planned | done | cancelled - на дату отчёта
          "price": "100000.00",
          "paid": "100000.00",          // выплачено за работу всего
          "paid_linked": "15000.00",    // из них платежами, явно привязанными к работе
          "remaining": "0.00"           // 0 для отменённой работы
        }
      ]
    }
  ],
  "totals": { "payable": "...", "paid": "...", "remaining": "...", "queued": "..." },
  "skipped_contracts": [],              // подписаны позже даты отчёта
  "warnings": [ { "code": "future_overpaid", "contract_id": "D-2", "message": "..." } ]
}
```

### `csv`

Плоская таблица для Excel. Суммы - с точкой и двумя знаками (`123456.00`), без пробелов.

| Колонка | Строка `work` | Строка `contract_total` |
|---|---|---|
| `row_type` | `work` | `contract_total` |
| `contract_id` | договор | договор |
| `work_id` | номер работы | пусто |
| `title` | название | подрядчик |
| `state` | `planned` / `done` / `cancelled` | пусто |
| `price` | цена работы | к оплате с учётом отмен (`payable`) |
| `paid` | выплачено | выплачено |
| `remaining` | осталось | осталось |
| `unallocated` | пусто | нераспределённый аванс |
| `queued` | пусто | в очереди |

Предупреждения в CSV не помещаются и выводятся в `stderr` строками `Предупреждение [договор]: ...`.

## Предупреждения (`warnings[].code`)

Предупреждения не останавливают расчёт - это повод свериться с данными.

| Код | Когда |
|---|---|
| `works_sum_mismatch` | сумма цен работ не равна сумме договора (итоги считаются от суммы договора) |
| `paid_for_cancelled_work` | к отменённой на дату работе привязан выплаченный платёж; деньги учтены как «не закреплённые за работами» |
| `work_overpaid` | привязанные к работе платежи превышают её цену; излишек учтён как «не закреплённый» |
| `contract_overpaid` | на дату отчёта выплачено больше, чем причитается |
| `future_overpaid` | на дату отчёта переплаты нет, но она возникнет, если учесть платежи и события из выгрузки, датированные позже |
| `no_date` | работа `done`/`cancelled` без даты события: считается наступившим |

## Ошибки данных (код 3)

Текст в `stderr`, все найденные ошибки разом, с файлом и строкой:

```
Ошибка: Ошибки во входных данных:
  works.csv:2: price: некорректная сумма 'abc' (ожидается число вида 1234.56, не больше двух знаков после точки)
  works.csv:3: status: неизвестное значение 'weird' (допустимо: planned, done, cancelled)
  payments.csv:4: платёж paid без даты оплаты paid_at
  платёж P-9: работа 'W-77' не найдена в works.csv
```

Номер строки - строка в файле, где заголовок считается первой.
