# contract-report

CLI-программа, которая по выгрузке из учёта (договоры, работы, платежи) строит отчёт **на заданную дату**:

- по каждой работе - цена, сколько выплачено, сколько осталось оплатить;
- по каждому договору - итоги: к оплате с учётом отмен, выплачено, остаток, аванс, платежи в очереди.

Главная сложность задачи: платежи по договору не привязаны к работам, а бухгалтеру нужно понимать, «за что уже рассчитались». Программа раскладывает такие платежи по принятым работам по порядку приёмки и всегда показывает, какая часть суммы по работе - это расчёт, а какая - явная привязка платежа. Допущения - в [DECISIONS.md](DECISIONS.md).

## Основные возможности

- Отчёт на любую дату (`10.11.2026` или `2026-11-10`): статусы из выгрузки «откатываются» на эту дату по датам событий - принятие работы, отмена, оплата, возврат.
- Деньги - точно, до копейки: `Decimal`, без `float` на всём пути от CSV до вывода.
- Три формата вывода: таблица в консоли, JSON, CSV (для Excel).
- Строгая проверка входных файлов: все ошибки показываются сразу, с именем файла и номером строки.
- Предупреждения о подозрительных данных (переплата, платёж по отменённой работе, сумма работ ≠ сумме договора и т.п.).
- Только стандартная библиотека Python, зависимостей нет.

## Установка

Нужен Python 3.9+ (проверено на 3.13).

```bash
cd contract-report-cli
python3 -m pip install -e .        # необязательно: даёт команду `contract-report`
```

Без установки программа тоже работает - запускайте из корня проекта через `python3 -m contract_report`.

## Запуск

```bash
# отчёт на 10.11.2026 по данным из ./data (таблица в консоли)
python3 -m contract_report --date 10.11.2026

# то же в JSON / CSV
python3 -m contract_report -d 10.11.2026 -f json
python3 -m contract_report -d 10.11.2026 -f csv -o report.csv

# один договор; другой каталог с данными
python3 -m contract_report -d 2026-11-10 -c D-1 --data-dir /path/to/data
```

Если `--date` не указана, берётся сегодняшняя дата. Полный справочник по аргументам, форматам и кодам возврата - [docs/API.md](docs/API.md).

## Тесты

```bash
python3 -m unittest discover -s tests     # без зависимостей
python3 -m pytest                         # если установлен pytest
```

Тесты покрывают разбор денег и дат, валидацию входных файлов, откат на дату (границы включительно), распределение платежей, сохранение денег (сумма по работам + нераспределённое = выплачено), эталонные цифры на данных из задания и CLI (форматы, коды возврата).
